# Location information of the water pumps

Location information of the water pumps

## Usage

``` r
location
```

## Format

A tibble with 299 rows and 6 variables

- pumpid:

  ID number of the water pump

- description:

  Name of the pump location

- x_arc1960:

  Easting in metres, Arc 1960 / UTM zone 37S

- y_arc1960:

  Northing in metres, Arc 1960 / UTM zone 37S

- lat_wgs84:

  Latitude in WGS 84 coordinate system

- long_wgs84:

  Longitude in WGS 84 coordinate system
