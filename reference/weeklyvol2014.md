# Weekly volume in year 2014

Weekly volume in year 2014

## Usage

``` r
weeklyvol2014
```

## Format

A tibble with 324 rows and 53 variables

- pumpid:

  ID number of the water pump

- 1, 2, ..., 52:

  Volume of water pumped in week 1 to 52 of 2014, one column per week

## Source

British Geological Survey, National Geoscience Data Centre:
